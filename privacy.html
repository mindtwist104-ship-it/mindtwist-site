Privacy Policy

MindTwist Studio Manager · Effective 6 November 2026

1. Who we are

MindTwist Studio Manager ("the tool") is a private, internal tool operated by Vishal Tyagi, an individual based in Delhi, India, to manage his own YouTube channel, MindTwist. The tool has a single user: the channel owner.

2. YouTube API Services

The tool uses YouTube API Services. By using the tool, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Information the tool accesses

  • The channel owner's own YouTube channel identity, needed to publish to it
  • The channel's own videos, playlists, captions and comments that the tool creates
  • The channel's own analytics reports (for example views, watch time, audience retention, click-through rate and traffic sources)
  • Video files the channel owner places in their own Google Drive for publishing

The tool does not access, collect or store data about any other YouTube user or channel, and it does not collect personal information from viewers.

4. How the information is used

Information is used only to publish and manage the channel owner's own videos and to analyse the channel's own performance in order to improve future videos. It is not used for advertising, profiling or any other purpose.

5. Storage and security

The OAuth access credential is stored encrypted in a private, access-controlled environment (GitHub Actions encrypted secrets) available only to the channel owner. Channel analytics summaries are stored in the owner's private files to inform future videos. Data is kept only as long as needed for these purposes and is deleted if the tool is retired.

6. Sharing

The tool does not sell, rent, share or transfer any data to third parties. Text content (such as video scripts and aggregated, non-personal channel performance figures) may be processed by an AI service provider solely to help produce the channel's own videos; no other users' personal data is involved.

7. Revoking access

Access granted to the tool can be revoked at any time through the Google security settings page at security.google.com/settings/security/permissions. On revocation, the stored credential stops working and is deleted.

8. Changes

Any change to this policy will be posted on this page with a new effective date.
